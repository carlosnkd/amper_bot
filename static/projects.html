Coddy

A chat assistant built on CrewAI, FastAPI, and Anthropic's Claude models. A three-agent pipeline (Planner, Coder, Reviewer) turns a short feature ticket into an editable, approval-gated plan before anything gets built, then a real implementation and a pass/fail review that sends the work back for another attempt when it fails. Progress streams live to the UI as it happens, and conversations persist so past plans and builds replay exactly as they looked. Chit-chat and one-off snippets skip the pipeline entirely and get answered directly.

Fathom

A chat assistant built on CrewAI, FastAPI and Gemini models. A multi-agent pipeline takes a manager's plain-English question, plans what data is needed, generates the SQL, runs it against the database, and turns the raw result into a short, readable answer.
